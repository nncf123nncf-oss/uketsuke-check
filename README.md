# 受付の名簿チェック

手元の名簿を貼るだけで、講座・勉強会・交流会の受付ができるWebページです。
100日100プロダクトチャレンジ Day097。

## できること

- 名簿を貼る（1行に1人。LINEやメモからのコピー、表計算の列をそのまま）。行の先頭の番号は外す
- 2列目以降（ふりがな・メモ）は名前の下に出し、探すときにも使う。「振込済」「支払済」などがあれば事前払い済みとして読み込む
- 当日払いの金額（1人あたり・任意）を入れると、未収と受け取り済みの金額も出る
- 名前の一部で探して「来た」「受け取った」を押す。ひらがなとカタカナ、全角と半角、空白の違いは気にせず探せる
- 上部に「来場 12／20人」「来場して未収 1人 3,000円」「受け取り済み 5人 15,000円」を常に出す
- 名簿にない人を当日追加できる
- 終わったら「まだ来ていない人」と「精算メモ」をコピーできる

## 保存について

- 名簿と受付の印は、この端末のブラウザ（localStorage）にだけ保存します。外には送りません
- 「全部消す」で消えます
- 登録・ログインはありません

## 作り

HTML1枚（`index.html`）。外部ライブラリなし。アクセス解析に Cloudflare Web Analytics を使っています（フッタに明記）。
